# Keepsake — Digital & Branding Agency (Vite + Pug + SCSS)

Адаптивний лендінг креативної агенції **Keepsake**, реалізований за допомогою шаблонізатора **Pug**, модульної архітектури **SCSS**, збирача **Vite** та інструментів автоматизації якості коду.

🔗 **Демо на GitHub Pages:** https://github.io

## Вимоги до середовища

- **Node.js:** v20.0.0 або вище (LTS)
- **npm:** v10.0.0 або вище

## Команди проєкту

- `npm install` — встановлення залежностей проєкту
- `npm run dev` — запуск локального сервера розробки
- `npm run build` — збірка оптимізованої продакшн-версії у папку `dist/`
- `npm run preview` — локальний перегляд зібраного проєкту
- `npm run images` — автоматична конвертація зображень у AVIF, WebP та JPEG (`400w`, `800w`) за допомогою `sharp`
- `npm run format` — автоматичне форматування коду (Prettier)
- `npm run lint` — перевірка стилів (Stylelint) та форматування (Prettier)

## Структура проєкту

- `src/layouts/` — базовий HTML-каркас сторінки (`main.pug`)
- `src/includes/` — мета-теги, підключення шрифтів та блоку `<head>`
- `src/data/` — масиви об'єктів з контентом секцій, портфоліо, журналу та навігації
- `src/mixins/` — перевикористовувані Pug-міксини (`+btn`, `+icon`, `+picture`, `+work-card`)
- `src/components/` — компоненти інтерфейсу (`header`, `footer`) та секції лендінгу (`sections/`)
- `src/pages/` — головна сторінка (`index.pug`), що наслідує базовий макет
- `src/styles/` — модульний SCSS (`utils/`, `base/`, `layout/`, `components/`, `main.scss`)
- `scripts/` — Node.js скрипт оптимізації растрових зображень

## Використані інструменти

- **Vite & Vituum** — швидкий dev-сервер та збирач статичних сторінок.
- **Pug** — препроцесор HTML із підтримкою наслідування, циклів, умов та міксинів.
- **SCSS (Dart Sass)** — модульна архітектура стилів із використанням `@use` та `@forward`, змінних, map-ів і функцій.
- **PostCSS & Autoprefixer** — автоматичне додавання вендорних префіксів під цільові браузери.
- **Sharp** — генерація адаптивних зображень у форматах AVIF, WebP та JPEG.
- **Prettier & Stylelint** — єдиний стиль форматування коду та контроль БЕМ-методології.
- **Husky & lint-staged** — автоматична перевірка коду перед кожним Git-комітом.
